# Privremeni ulaz klijentskih materijala

Ovde privremeno odloži sirove briefove, fotografije proizvoda, potvrde akcija i druge materijale koje tek treba povezati sa konkretnom objavom.

Kada se otvori paket objave, agent original bez izmene kopira u njegov `source/` folder i u `brief.md` beleži doslovan brief. Ne čuvaj završne rendere, captione ni radne fajlove u ovom folderu.

Sadržaj ovog foldera je privatan i ne verzioniše se u Git-u; ovaj `README.md` je jedini izuzetak.
