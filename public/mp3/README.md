# Muzički asseti

Ovaj folder sadrži šest standardnih numera koje Remotion renderer koristi za Reels.

## Poreklo

Metapodaci u MP3 fajlovima navode autora/nalog `isaakmoreira` i oznaku `made with suno`, sa datumom kreiranja 31. jul 2026. godine. Izvorni Suno ID svake numere ostaje sačuvan u njenim ugrađenim metapodacima.

| Fajl | Naslov |
| --- | --- |
| `clear-path.mp3` | Clear Path |
| `clear-path-ambient.mp3` | Clear Path |
| `open-sky-drift.mp3` | Open Sky Drift |
| `open-sky-drift-chill.mp3` | Open Sky Drift |
| `paper-sun-parade.mp3` | Paper Sun Parade |
| `paper-sun-parade-upbeat.mp3` | Paper Sun Parade |

## Prava korišćenja

Vlasnik projekta je potvrdio da je svih šest numera dozvoljeno za korišćenje u AU Šeki-Tilia materijalima. Agent nasumično bira jednu numeru za svaki novi Reels.

Numere se ne zamenjuju fajlom istog imena bez ponovnog renderovanja i vizuelno-audio pregleda svih aktivnih paketa koji ga koriste. Review manifest zaključava izabranu numeru SHA-256 hashom.
